# Smart Personal Finance & Expense Management System

## 📌 About the Project

A Python-based system designed to help students manage their personal finances by tracking income, expenses, budgets, and savings.

## 🎯 Objectives

* Track income and daily expenses
* Manage monthly budgets
* Calculate savings
* Analyze spending patterns
* Visualize financial data through charts

## 🛠️ Technologies

* Python
* Google Colab
* SQLite
* Pandas
* NumPy
* Plotly

## ✨ Main Features

* Income Management
* Expense Management
* Budget Tracking
* Savings Calculation
* Category-wise Expense Analysis
* Budget vs Actual Analysis
* Data Visualization


## 🚀 Future Enhancements

* Interactive web dashboard
* Login system
* Savings goal tracking
* Financial reports
* AI-based financial recommendations
